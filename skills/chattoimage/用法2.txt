bash

多轮对话与上下文
工作原理
ChatToImage 支持多轮对话，会自动记忆：

上次操作（换衣、换背景等）

上次主题（人物描述）

偏好设置（风格、场景）

最近生成的图片

示例
bash
# 第一轮：生成图片
python -m markflow.cli.commands execute ChatToImage \
    message="生成一个美丽女孩" \
    conversation_id="session1"

# 输出：生成了一张女孩图片

# 第二轮：换衣服（自动使用上一张图）
python -m markflow.cli.commands execute ChatToImage \
    message="换成红色裙子" \
    conversation_id="session1"

# 第三轮：换背景
python -m markflow.cli.commands execute ChatToImage \
    message="换成海滩背景" \
    conversation_id="session1"

# 第四轮：加配饰
python -m markflow.cli.commands execute ChatToImage \
    message="加猫耳" \
    conversation_id="session1"

高级配置
配置文件
ChatToImage 默认读取项目根目录的 config.yaml：

yaml
# config.yaml
llm:
  model: qwen2.5:7b
  api_type: ollama
  api_base: http://localhost:11434
  temperature: 0.3
  max_tokens: 2048

conversation:
  max_history: 10
  enable_context: true
  auto_save_context: true

defaults:
  steps: 30
  cfg_scale: 7.5
  width: 512
  height: 768
  strength: 0.55
  seed: -1

常见问题
Q1: 图生图需要指定图片吗？
A: 是的，图生图操作需要传入 image_path。如果是多轮对话，上一轮生成的图片会自动作为下一轮的输入。

Q2: 如何查看当前会话的上下文？
A: 使用 --verbose 参数可以看到上下文摘要。

Q3: 支持哪些图片格式？
A: 支持 jpg、jpeg、png、webp、bmp、gif 等常见格式。

Q4: 如何切换 LLM 模型？
A: 使用 --model 参数或在 config.yaml 中配置。

Q5: 生成速度慢怎么办？
A:

使用更小的 LLM 模型（如 qwen2.5:1.5b）

降低 steps 参数

启用 GPU（device="cuda"）

Q6: 如何保存结果到文件？
A: 使用 --output 参数：

bash
python skills/chattoimage/skill.py \
    --message "生成一个女孩" \
    --output result.json
Q7: 交互式模式下如何查看历史？
A: 交互式模式下输入 list 查看所有支持的功能，输入 clear 清除会话。
