ChatToImage 完整使用手册
一、两种调用方式
1.1 通过 Markflow CLI（推荐）
bash
python -m markflow.cli.commands execute ChatToImage message="你的自然语言描述"
1.2 直接运行技能文件
bash
python skills/chattoimage/skill.py --message "你的自然语言描述"
二、基础用法
2.1 文生图
bash
# 生成一张图片
python -m markflow.cli.commands execute ChatToImage message="生成一个美丽的女孩，在花园里"

# 指定模型
python -m markflow.cli.commands execute ChatToImage message="生成一个赛博朋克风格的城市" model="qwen2.5:14b"
2.2 图生图（需要输入图片）
bash
# 换衣服
python -m markflow.cli.commands execute ChatToImage \
    message="把她的衣服换成红色裙子" \
    image_path="input/girl.jpg"

# 换背景
python -m markflow.cli.commands execute ChatToImage \
    message="把背景换成海滩" \
    image_path="input/girl.jpg"

# 加猫耳
python -m markflow.cli.commands execute ChatToImage \
    message="加猫耳" \
    image_path="input/girl.jpg"

# 风格转换
python -m markflow.cli.commands execute ChatToImage \
    message="转成油画风格" \
    image_path="input/girl.jpg"
2.3 多轮对话（带上下文）
bash
# 第一轮
python -m markflow.cli.commands execute ChatToImage \
    message="生成一个女孩" \
    conversation_id="my_session"

# 第二轮 - 自动继承上下文
python -m markflow.cli.commands execute ChatToImage \
    message="把她的头发换成粉色" \
    conversation_id="my_session"

# 第三轮
python -m markflow.cli.commands execute ChatToImage \
    message="换成海滩背景" \
    conversation_id="my_session"

五、完整使用示例
5.1 单人像编辑工作流
bash
# 1. 先生成一张图
python -m markflow.cli.commands execute ChatToImage \
    message="生成一个美丽亚洲女孩，长发，白色连衣裙" \
    conversation_id="girl_edit"

# 2. 换衣服
python -m markflow.cli.commands execute ChatToImage \
    message="换成红色旗袍" \
    conversation_id="girl_edit"

# 3. 换背景
python -m markflow.cli.commands execute ChatToImage \
    message="把背景换成樱花树下" \
    conversation_id="girl_edit"

# 4. 加猫耳
python -m markflow.cli.commands execute ChatToImage \
    message="加猫耳" \
    conversation_id="girl_edit"

# 5. 换表情
python -m markflow.cli.commands execute ChatToImage \
    message="让她笑起来" \
    conversation_id="girl_edit"
5.2 目录批量处理（通过 Shell 循环）
bash
# 对 input/ 目录所有图片执行相同操作
for img in input/*.jpg; do
    python -m markflow.cli.commands execute ChatToImage \
        message="把背景换成海滩" \
        image_path="$img" \
        conversation_id="batch_$(basename $img .jpg)"
done
5.3 自定义 LLM 参数
bash
# 使用不同的 LLM 模型
python -m markflow.cli.commands execute ChatToImage \
    message="生成一个赛博朋克风格的城市" \
    model="qwen2.5:14b"

# 使用 OpenAI 兼容 API
python -m markflow.cli.commands execute ChatToImage \
    message="生成一个女孩" \
    api_type="openai_compatible" \
    api_base="http://localhost:8000/v1" \
    api_key="your_key"
六、ChatToImage 完整参数
参数	说明	默认值
message	必填 用户自然语言描述	-
image_path	输入图片路径（图生图需要）	-
model	LLM 模型名称	qwen2.5:7b
api_type	API 类型 (ollama/openai/openai_compatible)	ollama
api_base	API 地址	http://localhost:11434
api_key	API Key（OpenAI 需要）	""
conversation_id	会话 ID（多轮对话）	default
stream	是否流式输出	false
